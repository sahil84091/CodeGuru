# CodeGuru - Project Context

## 1. Product Overview

CodeGuru is a gamified coding and learning platform designed primarily
for college students.

The goal is to make learning programming more interactive and engaging
by combining coding education with game-like experiences.

---

## 2. Target Users

Primary users:

- College students
- Beginners learning programming
- Students learning DSA
- Students learning Web Development
- Students preparing for coding interviews

---

## 3. Learning Areas

### Programming Languages

Initial supported languages:

- C++
- Java
- Python

### Data Structures & Algorithms

Planned topics include:

- Arrays
- Strings
- Linked Lists
- Stack
- Queue
- Searching
- Sorting
- Recursion
- Trees
- Graphs
- Dynamic Programming

### Web Development

Planned topics:

- HTML
- CSS
- JavaScript
- React

---

## 4. Gamification System

CodeGuru will use game mechanics to make learning engaging.

Core mechanics:

- XP
- Levels
- Missions
- Challenges
- Learning Map
- Achievements
- Leaderboards
- Daily Challenges
- Streaks
- Unlockable Content

---
